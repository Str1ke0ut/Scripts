# Kaivaz Projects

Recovered and organized project source from earlier Kaivaz development work.

## Projects

- **Rune** — local Tkinter AI assistant using Ollama, with memory, chat history, voice output, and coding helpers.
- **FrameBoard** — Python/Tkinter animation reference-board tool using Pillow.
- **Elemental Legends** — Pygame action-game prototype with elemental abilities and a scrolling world.
- **Windows 98 Simulator** — Tkinter visual Windows 98-style desktop simulation with built-in mini apps.
- **Creator Studio** — desktop creator/project-management application originally developed as STR!KE_0UT STUDIO v1.1.

## Notes

These are recovered source snapshots, organized for preservation. Some projects may require additional assets or dependencies that were not part of the recovered source snapshot.
